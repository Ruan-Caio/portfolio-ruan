# RCD | ruan.devbr — Portfólio

Portfólio pessoal desenvolvido para apresentar minha trajetória como estudante de desenvolvimento de software, meus projetos práticos, conhecimentos e serviços na área de desenvolvimento web.

O projeto busca demonstrar minha evolução na programação e apresentar soluções digitais que venho desenvolvendo e estudando.

## Sobre o projeto

Este portfólio foi criado com o objetivo de reunir meus projetos, apresentar minhas habilidades e facilitar o contato com pessoas e empresas interessadas em soluções digitais.

O site possui uma interface moderna, responsiva e com identidade visual voltada para tecnologia.
